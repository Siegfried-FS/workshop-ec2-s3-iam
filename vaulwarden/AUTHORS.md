## Sobre el Proyecto

Este workshop fue creado en **febrero de 2026** como material educativo para la comunidad de AWS User Group Playa Vicente, con el objetivo de enseñar despliegue de aplicaciones en AWS EC2 de forma progresiva.

## AWS User Group Playa Vicente

Somos una comunidad de entusiastas de AWS en Playa Vicente, México, dedicados a:
- 📚 Compartir conocimiento sobre tecnologías cloud
- 🤝 Crear una red de profesionales de AWS
- 🎓 Organizar workshops y eventos educativos
- 💡 Promover mejores prácticas en la nube
